Bubble Gun smoke check

bugs/ricart-agrawala-gate exercises a distributed lock whose deferred-reply goroutine can violate mutual exclusion. A program failure means a schedule exposed that bug.

What is the bug?

Each node waits for every peer reply before entering its critical section. Receiving the final reply closes a gate channel, waking both the application goroutine and a deferred-reply goroutine.

The correct order runs the application first, which marks the lock as held. The buggy order runs the deferred-reply goroutine first. It observes the temporary released state and sends replies that should remain deferred, allowing another node to enter concurrently.

Why does FIFO miss it?

FIFO consistently delivers requests in their queued order and schedules the application before the deferred-reply goroutine. Exposing the bug requires both a reordered request and a non-FIFO local scheduling choice. CHESS and DPOR explore those alternatives systematically, while PCT and Random sample them.
